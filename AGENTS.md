# Project Guidelines

## Core Principles
All code and architectural implementations must adhere strictly to YAGNI and KISS:
- **YAGNI (You Aren't Gonna Need It)**: Avoid speculative features, unused abstractions, redundant stores, and premature generalizations. Only build what is directly needed for current requirements.
- **KISS (Keep It Simple, Stupid)**: Favor simple, readable, and fundamental implementations over complex layers. Rely on native language and framework primitives (such as `import.meta.env`, native `fetch`, standard React hooks) rather than overengineering.
